tmux-next

Connect to your tmux-next server. It runs on your own machine — this app only remembers where it lives.

The address must be https:// (or a local http:// on the same machine). If your server has a login (most do), tap Sign in first below, log in, then tap Connect — the login stays with this app. The address is kept on this device only.
