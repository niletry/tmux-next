自托管 · tmux web 客户端

在手机上用你的 tmux

tmux-next 是一个自托管的网页客户端。它列出你机器上所有的 tmux 会话， 显示每个会话的最新画面，让你在手机上点进去继续操作——特别适合盯着跑在 里面的 Claude Code。

长什么样

两个界面

所有会话列在一起，每个带最后几行输出。等你回复的会话排在最前面，一眼就能看到。

点进会话就是完整终端。软键盘没有的键（Esc、Ctrl、方向键）做成了底部工具条。

安装

一行命令跑起来

$ bunx tmux-next

需要 tmux 3.2+ 和 Bun。跑起来后打开 http://127.0.0.1:7682/，就能看到本机所有 tmux 会话。

想从手机连，需要在前面架一个反向代理来做 HTTPS 和登录认证——因为这个服务本身 没有内置认证，直接暴露到公网等于把机器的 shell 交出去。 照着 用 Caddy 部署的指引 一步步做即可。
